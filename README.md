# CodeAlpha Python Internship Projects

## Overview

This repository contains the Python projects completed as part of the CodeAlpha Python Programming Internship. The projects demonstrate fundamental Python programming concepts, including file handling, conditional statements, loops, functions, and user interaction.

---

## Projects Completed

### 1. Hangman Game

A console-based word guessing game where the player attempts to guess a hidden word within a limited number of attempts.

#### Features

* Random word selection
* Limited guessing attempts
* User-friendly interface
* Win/Loss detection

**File:** `hangman_game.py`

---

### 2. Stock Portfolio Tracker

A Python application that helps users track stock investments and calculate the total value of their portfolio.

#### Features

* Portfolio management
* Investment tracking
* Portfolio value calculation
* Text file storage

**File:** `stock_portfolio_tracker.py`

---

### 3. Basic Chatbot

A simple chatbot that interacts with users using predefined responses.

#### Features

* Interactive conversation
* Predefined responses
* Simple command handling
* Beginner-friendly implementation

**File:** `basic_chatbot.py`

---

### 4. File Automation Script

A utility script that automatically organizes files into appropriate folders based on their file types.

#### Features

* Automatic file sorting
* Folder creation
* File management
* Improved organization

**File:** `file_automation_script.py`

---
